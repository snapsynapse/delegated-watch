# Attribution
## Origin
This project was inspired by Nate B. Jones' post, [Build a Token Burn Dashboard to Track What Your AI Actually Does](https://natesnewsletter.substack.com/p/token-burn-dashboard). The framing taken from it: token burn is a proxy for delegated work, and the point of measuring it is a learning loop, not a leaderboard.
No code was copied from that post or from any contemporary project surveyed during this project's development. Where a convention here resembles another project's, it is because both were built independently from the same source framing, not because of any shared code or lineage.
